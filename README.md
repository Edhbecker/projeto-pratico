# Caça ao Tesouro — jogo simples de terminal.

## Versionamento Semântico

Este projeto utiliza o Versionamento Semântico para identificar e organizar as versões publicadas. O formato adotado é:

`MAJOR.MINOR.PATCH`

- **MAJOR:** deve ser incrementado quando houver mudanças incompatíveis com versões anteriores, que podem exigir adaptações de quem utiliza o projeto.
- **MINOR:** deve ser incrementado quando forem adicionadas novas funcionalidades compatíveis com as versões anteriores.
- **PATCH:** deve ser incrementado quando forem realizadas correções de erros ou pequenos ajustes compatíveis com as versões anteriores.

A versão `v1.0.0` representa a primeira versão estável do projeto.
